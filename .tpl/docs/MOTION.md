# 动效清单与边界

参考站 2026-10-24。首页首屏按 0.2 / 0.4 / 0.6 秒错峰入场；内容有位移与 0.8→1 缩放两类入场；菜单遮罩与导航错峰、逐字悬停、数字计数、合作伙伴循环、流程卡片 sticky、服务图文切换、400svh 视频墙缩放（3.25→1、0.3→1 透明度）、顾问卡片悬停、评价拖拽回弹、FAQ 高度展开、图库切换、弹层关闭均有独立实现。手机切换为单列并取消流程卡片 sticky，视频墙为 300svh。减少动态效果时禁用入场、位移、循环与视频自动播放。

原站使用 Framer 平台自带的滚动与组件运行时，本工程采用 React / Framer Motion 重写。原站全部页面、全部断点的运动轨迹、时间曲线、磁吸参数和逐帧状态尚未完成一一比对；当前不声明完整动效一致。
